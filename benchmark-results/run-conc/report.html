Batch vs Live Traffic Isolation

Setup

ModelQwen/Qwen3-8B on 1× NVIDIA A100-80GB (max concurrency ~198 @ 4096 tokens)
Live trafficguidellm --profile concurrent at [5, 30, 50, 80] concurrent requests, 120s per phase, 60s idle between
Batch load5×100 requests submitted at start + 5×100 overlapping during first burst (~1500 tok/req, faker prompts)
EPPFlow control enabled (maxRequests: 50), optimized-baseline profile
Gateprometheus-budget, max_concurrency=50, fallback=0.0

Scenarios

Baseline

No batch stack installed. Pure live traffic only.

Sync (default)

Batch processor: per_endpoint=10, AIMD enabled. Out-of-box settings.

Sync (aggressive)

Batch processor: per_endpoint=100, AIMD disabled. Worst-case batch flooding.

Gated (async)

Async dispatch with prometheus-budget gate. Batch held back when GPU busy.

Analysis

With Qwen3-8B on A100-80GB (max concurrency ~198), the GPU has substantial headroom at all tested concurrency levels (5–80). Even at 80 concurrent live requests, the GPU is only at ~40% capacity.

Sync-default (per_endpoint=10, AIMD on): batch processor is limited to 10 concurrent inference requests. With AIMD further reducing on backpressure, batch adds negligible load. TTFT is indistinguishable from baseline.

Sync-aggressive (per_endpoint=100, AIMD off): batch floods the GPU with up to 100 concurrent requests. At low concurrency (5), this doubles ITL (12ms vs 6ms) because batch consumes half the GPU. But batch completes quickly (all 1000 requests done before phase 3), so higher concurrency phases see no impact.

Gated: the prometheus-budget gate monitors vllm:num_requests_running and holds batch back when utilization exceeds the threshold. With this model, the gate is partially effective — it slows batch during bursts but doesn't fully close because the GPU has abundant headroom.

Key takeaway: for this model/GPU combination, the gate's value is limited because the GPU never truly saturates. A larger model (tighter GPU headroom) or a constrained GPU (fewer KV cache blocks) would show more dramatic batch interference in sync mode and correspondingly more gate value.
